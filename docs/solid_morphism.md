# CharisOS Solid Morphism

The CharisOS visual language intentionally moves away from generic glassmorphism and toward strong, tactile surfaces.

## Core principles

- solid surfaces instead of transparent acrylic layers
- controlled shadows and beveled separation
- crisp borders and outlines
- consistent radii and spacing tokens
- clear hierarchy between base, raised, and recessed panels
- interaction states that include physical surface changes, not only color swaps
- reduced blur and motion in favor of intentional structure

## Design goals

The UI should feel like an engineered operating system, not a marketing dashboard. The desktop, taskbar, dialogs, and widgets share one visual language so window chrome, controls, and app surfaces form a coherent system.

## Planned token model

- palette: background, surface, elevated surface, border, accent, text colors, status colors
- typography: sizes, weights, fallback fonts, text metrics
- spacing: controls, gaps, paddings, panel seams
- elevation: shadow depth, highlights, insets, offsets
- motion: hover, press, window open/close, notification arrival

This document is the design baseline for the future UI toolkit and desktop shell.
